# 한국어 항목 구분 및 답 없음 학습 v2

이전 분리 모델의 해외 식비·숙박비 혼동, 부서 추출 실패, 없는 기관명 오답을 보강했다. 대화 학습은 포함하지 않았다. 자체 trid 가중치에서 이어 학습하며 외부 LLM 가중치나 답변 API는 사용하지 않았다.

## 학습

- v2: 국내/해외 식비, 국내/해외 숙박비, 정산 기한, 담당 부서, 기관명, 일비의 8개 항목. 학습 6,720문항, 검증 560문항, 최초 시험 1,120문항. 문서·문장 양식·값을 분할했다.
- 구간/존재 여부 모델을 v1에서 각각 1,200단계 추가 학습했다. 둘 다 전체 검증 손실 최소인 100단계를 선택했다. 마지막 가중치를 무조건 채택하지 않는다.
- v2-refined: 구간 모델은 그대로 보존하고, 존재 여부만 1,600단계 추가 학습했다. 원본과 사실에 맞는 미기재 문장을 추가한 사본으로 학습 13,440문항 / 검증 1,120문항을 구성했다.
- refined 체크포인트는 균형 검증 정확도가 최대인 1,400단계(860/1,120, 76.8%)를 선택했다. 동률이면 CE가 낮은 쪽을 선택한다. 선택된 CE는 1.438로, 초기 0.630보다 높다. 따라서 확률 보정이 좋아졌다고 주장하지 않는다. 출력 소프트맥스는 신뢰도가 아니다.
- 배치 16, 학습률 0.0001, 시드 42, fresh AdamW. 기존 가중치와 활성 모델 설정을 보존했다.

## 같은 1,120문항의 개발 비교

| 지표 | 기존 v1 | v2 | v2-refined |
|---|---:|---:|---:|
| 답 있음 정답 | 162/560 | 354/560 | 401/560 |
| 답 없음 올바른 보류 | 251/560 | 262/560 | 519/560 |
| 존재 여부 정답 | 648/1,120 | 688/1,120 | 991/1,120 |
| 전체 정답 | 413/1,120 | 616/1,120 | 920/1,120 |
| 답 있다고 가정한 구간 정답 | 249/560 | 477/560 | 477/560 |

최초 v2 평가는 학습 전 고정한 시험이었다. 그 결과를 본 뒤 refined 학습 방향을 정했으므로 refined의 1,120문항 결과는 개발 회귀 평가다. 새 미사용 시험으로 표현하지 않는다. 시험 문항을 학습 파일에 넣지는 않았다.

refined의 항목별 답 있음 / 답 없음 정답: 해외 식비 65/70 · 46/70, 해외 숙박비 66/70 · 70/70, 담당 부서 39/70 · 69/70, 기관명 37/70 · 70/70. 나머지 항목 및 오답 혼동은 JSON의 `by_field`, `wrong_field_confusions`에 있다.

과거 T01 및 값 변경 8문항은 v1 4/8 → refined 8/8, 기관명 없음 0/2 → 2/2다. 하지만 refined 학습 완료 전 새로 작성한 120문항 진단은 88/120이며 답 없음은 8/24, 그중 기관명 없음은 0/6이다. 기관명 부재 문제가 모든 문서에서 해결된 것은 아니다. 이 진단은 짧은 합성 문서의 작은 개발자 작성 검사이며 실무 벤치마크가 아니다.

넓은 독해 197문항은 refined 5/197이다. 일반 한국어 독해 개선으로 해석하지 않는다. 기본 대화·기관 생성 모델을 바꾸지 않았다.

## 재현

```sh
.venv/bin/python scripts/prepare_presence_v2.py --verify
.venv/bin/python scripts/evaluate_short_reader.py --run runs/trid-korean-short-v2-refined --data data/korean-short-v2 --baseline-run runs/trid-korean-short-v1 --development-regression --audit-cases reports/korean-short-v2-fresh-audit-cases.json --output reports/my-v2-recheck.json
```

`prepare_short_reader_v2.py`와 `prepare_presence_v2.py`는 자료 생성 코드다. 새 생성 경로/버전을 사용하고 기존 자료를 덮어쓰지 않는다. 각 구성요소의 `training.json`에 부모 해시, 자료 해시, 최선 단계와 실제 완료 단계를 기록했다.

- 평가: `reports/korean-short-v2-evaluation.json`, `reports/korean-short-v2-refined-evaluation.json`
- 모델: `runs/trid-korean-short-v2-refined`
- 두 모델 합계 34,736,642파라미터, FP32 파일 합계 138,959,032바이트(132.5MiB). 양자화·Pi 실측은 수행하지 않았다.

## 현재 우선순위

사용자 요청에 따라 PDF 화면 작업은 중단하고 시험 서버도 종료했다. 작성한 로컬 입력 코드와 샘플은 보존했지만, 이 단계의 중심 결과는 모델 학습이다. 다음 v3에서는 같은 질문에 대해 해당 항목을 비슷한 다른 항목으로 바꾼 대조 쌍을 추가하고, 위 회귀 검사와 새 고정 진단으로 확인한다.
