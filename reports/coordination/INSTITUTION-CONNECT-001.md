## 2. 법령 별표

**별표 번호 결함 수정**
- 문제: 말뭉치 제목 "[별표 0006]"이 원문 "[별표 6의2]"인 경우가 있다.
- 수정: 별표 문서의 번호를 첫 구간의 원문 캡션(`[별표 6의2]`)에서 읽는다. 본문 인용("별표 6의2", "별표 2")도 `의N`까지 읽어 같은 법령 안에서만 연결한다.
- 캡션이 없는 별표 24건은 연결하지 않는다. 제목 숫자로 추정하지 않는다.
- v5에서 제목 숫자와 캡션 번호가 다른 별표는 43건이다. 이전 방식이었다면 잘못 연결될 수 있었다.

**검토된 행만 사용**
- `data/law-byl/v2-structure-001-rows-001/queryable-rows.jsonl`에서 `review == ai_visual_review_match`인 행만 읽는다. v5에 있는 문서 기준 30행(별표 6개)이다.
- `candidate_unreviewed` 1,688행과 not-queryable 표(nested/irregular/differs)는 읽지 않는다(테스트 있음).

**검토된 행을 근거에 넣는 방식**
- 질문과 관련성 검사를 통과한 별표 1개만 고른다.
- 그 표의 캡션·단위·개정일·법령 시행일·행(열 이름: 값)·비고를 한 덩어리로 넣는다.
- 길면 생략한 행 수를 적고, 잘린 비고는 "(비고 일부 생략, 원문 확인)"으로 표시한다.
- 이 덩어리는 `derived`다:
  - 원문 인용(원문 일치)으로 표시되지 않는다(테스트 있음).
  - 값 응답 버전과 독해기에는 넣지 않는다.
- `scope`에 "B가 원본 렌더링과 대조한 표 행 … 원문 인용으로 표시하지 않으며, 승인된 값이나 법률 자문이 아닙니다"를 적는다.

**문맥 한도 회귀(실사이트에서 발견, 수정)**
- 증상: 검토 행을 추가한 직후, "공무원 여비 규정에서 국내 출장 식비는 하루 얼마야?"가 실사이트에서 HTTP 422(문맥 한도 초과)를 냈다. 근거 5,013자였다.
- 수정 내용:
  - 행으로 대체한 연결 별표는 평문 구간을 뺀다.
  - 근거를 `CONTEXT_CHARS` 3,600자 안으로 줄인다. 빼는 순서는 연결 구간 → 적용 문서의 약한 구간이다.
- 수정 후 같은 질문의 근거는 3,170자이고, 실사이트에서 200으로 답했다.

## 3. C-029 보호 계약 (실제 `/api/ask` 경로)

HTTP 테스트 `ProtectedPassageApiTests`가 case / value(llama) / reader 세 버전을 모두 거친다. 모델 호출은 가로채서 모델에 들어간 텍스트를 기록한다.

**privacy 구간**

| 경로 | 결과 |
|---|---|
| 최상위 근거가 보호 구간 | `not_found/protected`, 모델 호출 0 |
| 같은 문서 고정(pinned) | 다른 구간만 사용 |
| 법령 본문이 인용한 별표가 보호 구간 | 연결에서 빠짐 |
| 모든 경우 공통 | 보호 원문과 구간 id가 모델 입력과 응답 본문 어디에도 없음 |

**수정한 결함**
- 시작 시 검사: review의 privacy id가 색인에 없으면 서비스를 시작하지 않는다(fail closed). v5는 2/2 일치, value_hold는 87/87 일치.
- 이중 방어: 선택 결과에 보호 구간이 섞이면 RuntimeError를 낸다.
- 보호 구간이 최상위 근거인지는 검색 범위(기관·고정 문서) 안에서 판정한다. 다른 구간이 관련성 검사를 하나도 통과하지 못해도 판정한다. 이전에는 "해당 기관 자료에 근거 없음"(`institution_no_match`)으로 끝났다.
- 기관 약한 일치 판정보다 보호 판정을 먼저 한다.

**value_hold 구간**
- 값 버전과 reader: hold 구간을 모델 입력에서 뺀다. 뺐다는 안내를 붙인다.
- 모든 구간이 hold이면: 이전에는 "관련 구간을 찾지 못했습니다"(사실과 다름)였다. 이제 `review/value_hold`로 "원문(쪽)에서 확인"을 안내하고 모델을 부르지 않는다.
- case 버전: hold 숫자는 인용으로도 해설로도 쓰지 않는다. 숨긴 문장이 있으면 `raw_output`도 응답에서 뺀다(`raw_output_withheld`).

**적용 대상 불일치 (공무원 법령 ↔ 공무원 아닌 질문)**
- 답변 본문 맨 앞에 "「공무원 여비 규정」은 국가공무원에게 적용되는 규정 … 그 기관의 지급액으로 보지 말고 기관 자체 규정을 확인"을 표시한다. 접기 안만이 아니다.
- 숫자가 든 해설 문장과 원출력을 숨긴다. 값 응답은 'review'로 내린다.
- 질문에 '공무원'이 있으면 적용하지 않는다.
- 실사이트 확인:
  - 기본 버전: "공공기관 직원 국내 출장 식비 기준은?" → 경고문, 숫자 해설 3개 숨김, 원출력 차단
