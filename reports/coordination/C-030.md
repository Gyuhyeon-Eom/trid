## 3. 보호(privacy·hold) 실 경로

- **privacy 2구간:** 이전 배포와 TABLE-LINK의 모든 실 UI 응답(32건)에서 hits·후보 id **0회**. 해당 매뉴얼을 직접 겨냥한 P1 질문 포함.
  - P1 응답 본문은 저장하거나 보고하지 않았다(id 대조만).
  - **관찰 범위 안에서 통과.**
- **구현 방식(참고, 판정 근거 아님):** `679004f`는 보호 구간 점수를 `-inf`로 두고, 사용되면 요청을 실패시키는 불변식 검사와 누락 id 개수 검사를 둔다(C-029에서 지적한 "점수 0 의존"을 보완). A의 `ProtectedPassageApiTests`는 모델 호출을 가로채는 입력 차단 증거다. 실제 모델 출력의 hold 처리와는 구분한다.
- **hold 87구간:** H1(hold 구간이 30개인 비행절차설계요령 질문)에서도 hits에 hold 구간이 들어오지 않았다. **실 UI에서 hold 안내가 실제로 나온 사례는 아직 없다.** case 모드 동작은 C-029 합성 시험으로만 확인됐다.
