## 3. 원본(Qwen3-1.7B 기본) 교체 적합 여부: 근거 정리

**측정된 것 (개발 대화 의미 판정):**
- Qwen2.5-7B는 원본보다 생략형 후속과 번역 핵심을 일관되게 더 잘 받았다(두 설정 모두).
- 그러나 **교체를 막는 실패가 두 설정 모두에 남아 있다:**
  - **요청 없는 문장 단위 중국어 전환:** greedy 1회에서도 4/48, 그중 1건은 무관한 내용 동반. 한국어 서비스에서 바로 보이는 실패다.
  - **업무 규정 수치 날조:** 연가 근속표 등. 원본도 같은 실패가 있지만 줄지 않았다.
  - **다듬기 지시 실패**(t2~t4)와 경계 수준의 조건 위반.
- 응답 시간은 원본보다 3~4배 길다(같은 맥, 같은 런타임).

**측정되지 않은 것 (교체 판단에 필요하지만 근거가 없음):**
- **업무 경로 성능:** C 고정 32문항의 서비스 결정과 해설, case 계약(C-028 형식), 값 계약 고정 suite(RAG310·probe), 실 UI 업무 회귀. Qwen2.5-7B로는 한 번도 측정하지 않았다.
- 서비스 경로(라우터, 숫자 필터, 근거 검색)를 통과했을 때의 일상 대화 결과(C-031 형식).
- 독립 평가(개발 대화가 아닌 C 단독 시나리오, 블라인드).
- temperature 0의 재현성, 여러 실행에 걸친 언어 전환 빈도.

**정리:**
- 현재 근거로는 **원본을 Qwen2.5-7B로 교체하기에 적합하다고 판정할 수 없다.**
  - 일상 대화 일부 축에서는 낫다.
  - 하지만 언어 전환과 규정 날조가 남아 있고, 업무 경로 성능은 전혀 측정되지 않았다.
- 교체를 검토하려면 위 "측정되지 않은 것"이 같은 조건(원본과 같은 artifact, 같은 서비스 경로)으로 먼저 측정돼야 한다. 이 보고는 그 실행을 자동으로 제안하거나 시작하지 않는다. 결정은 사용자와 감독이 한다.
