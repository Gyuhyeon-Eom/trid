## 7. prepare/load 호환성 (실제 실행)

| 검사 | 결과 |
|---|---|
| 기존 로더 `trid.text.read_rows` + `encode_example`(1,024) | 30/30 통과 |
| 프롬프트 + 생성 여유 128토큰 ≤ 1,024 | 30/30 통과 |
| 기존 혼합 단계 `prepare-teacher`(mix-04 + 파일럿 5%) | 생성·가중치 유효(양수·유한), 파일럿 24행 질량 0.05, 검증 파일 부모와 동일 |
| 값 복사 제한 디코더(`trid/constrained.py`, 최대 2쌍)가 정답을 완성 답으로 수용 | 조건 5/5, 예외 5/5, 표 5/5, 결합 5/5, 수치 변경 5/5, **설명 0/5** |
| 답 길이(토큰) | 값 유형 최대 32, 설명 최대 144 |

해석: 조건·예외·표·결합·수치 변경은 기존 학습·디코딩 경로와 호환된다. **근거 기반 설명은 SFT 학습 로더와는 호환되지만 값 복사 제한 디코딩과 RAG310·민감도 평가 형식과는 호환되지 않는다.** 설명을 값 추출 문제로 바꾸지 않았다. 필요한 변경 범위: (1) 설명 요청 시 제한 디코딩을 끄거나 결론·근거 인용 구간만 원문 복사로 제한하는 별도 문법, (2) 생성 길이 160토큰 이상(현재 평가 64, 빌더 여유 128), (3) 결론·근거·조건 정확성과 부가 주장 채점 평가기. 이 변경은 A/총괄 범위와 겹치므로 승인 전 구현하지 않았다.
