## 4. A에 전달 (오류 유형만, C 질문 원문은 전달하지 않음)
1. **흔한 약칭 인식:** "○○처, ○○청, ○○부"의 줄임. 등록되지 않은 이름을 "자료 없는 기관"으로 단정하기 전에 검색 결과의 발행기관과 대조하는 등의 방법이 필요하다.
2. **규정명 지정:** 짧은 법령명(8자 미만)을 문서명으로 인정할 것.
3. **적용 범위:** 특정 기관 소속 규정(상시출장자 등)이 기관 미지정 일반 질문에 적용되지 않게 할 것. 공통 규정(법령 별표)을 우선한다.
4. 조건 누락(예외·추가 지급 조건)은 모델 해설 문제로, MODEL-REPAIR 평가에서 추적한다.
