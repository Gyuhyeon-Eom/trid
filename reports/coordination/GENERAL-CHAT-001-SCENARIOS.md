# GENERAL-CHAT-001 → A: 일상 대화 개발용 시나리오 8개 (B 작성)

- **용도:** A가 일상 대화의 라우팅·문맥·후처리를 진단하고 수정할 때 쓰는 개발용 대화다.
  - 학습 데이터가 아니다.
  - 평가셋이나 벤치마크가 아니다. 독립성도 주장하지 않는다.
  - B가 새로 썼다. C의 평가 원문은 보지 않았다.
- **정답 문구는 없다.** 실패만 관찰한다. 업무 금액이나 기한의 정답도 새로 만들지 않았다.
- B는 코드와 UI를 바꾸지 않았다. 새 GPU 0.
- **실행 방법:**
  - 실제 입력창이나 `/api/ask`(`scope: "workspace"`)로 한 턴씩 보낸다.
  - 시나리오를 시작할 때마다 ✎ 새 대화(`/api/clear`)로 시작한다.
  - 응답의 `intent`·`status`·`commentary_notes`와 표시된 배지를 함께 기록한다.

## 실패 관찰 기준 (모든 턴 공통)

| 코드 | 실패 | 관찰 방법 |
|---|---|---|
| F1 검색 강요 | 일상 대화 턴이 검색 경로로 간다 | `intent ≠ chat`이거나, "근거 못 찾음"·"해당 기관 자료 없음"·적용 문서·되묻기 배지가 나온다 |
| F2 맥락 분실 | 같은 대화 안에서 사용자가 앞서 말한 사실·조건·대상을 잊거나 바꾼다 | 아래 각 시나리오의 "기억할 것"과 대조한다 |
| F3 기록 덤프 | 이전 대화 기록, 시스템·역할 지시문, 내부 메모, 원문 구간을 그대로 늘어놓는다 | "사용자:", "assistant", "근거:", 지시문 문장 같은 형식이 답에 섞인다 |
| F4 반복 | 같은 문장이 되풀이된다. 또는 직전 답을 거의 그대로 다시 낸다 | 문장 단위로 중복을 본다. `commentary_notes`의 "반복 N회 생략"도 기록한다 |
| F5 지시·질문 복사 | 사용자 질문이나 시스템 지시를 그대로 되읊는다. 답은 없다 | `model_failure` 여부. 답과 질문의 겹침을 본다 |
| F6 임의 기관 규정 답 | 기관을 말하지 않은 업무 질문에 특정 기관 규정·금액·기한으로 단정해 답한다 | 기관을 되묻거나, 명시한 기관에서만 찾았는지 본다 |
| F7 세션 누설 | 새 대화 뒤에도 이전 대화의 이름·일정·조건을 안다 | 시나리오 8 |
| F8 근거 없는 수치 | 일상 답에 사용자가 주지 않은 업무 수치·조문을 단정한다 | 숨김 안내(`commentary_notes`)가 붙었는지와 함께 기록한다 |

- **실패가 아닌 것:**
  - 업무 질문 턴이 검색 경로로 가거나 기관을 되묻는 것
  - 답 문체가 무난하거나 짧은 것
  - 이 자료로는 모른다고 말하는 것

## 시나리오

### 1. 가벼운 잡담 (4턴)
1. 안녕하세요, 오늘 좀 피곤하네요.
2. 점심 뭐 먹을지 고민이에요.
3. 아까 피곤하다고 했잖아요. 커피 말고 기운 나는 거 뭐 없을까요?
4. 고마워요, 오후도 힘내볼게요.
- **기억할 것:** 피곤함(3턴).
- **주로 볼 것:** F1(전 턴), F4, F3.

### 2. 기분 공감 (4턴)
1. 보고서가 반려돼서 좀 속상해요.
2. 팀장님이 표현이 너무 딱딱하대요.
3. 이럴 때 마음을 어떻게 추스르면 좋을까요?
4. 그래도 내일 다시 써야겠죠.
- **기억할 것:** 반려된 이유가 "딱딱한 표현"이라는 점(3·4턴).
- **주로 볼 것:**
  - F1: "보고서"라는 단어로 검색 경로에 가지 않아야 한다.
  - F2, F4.

### 3. 사용자 제약을 기억한 추천 (5턴)
1. 저는 매운 걸 못 먹고 견과류 알레르기가 있어요.
2. 다음 주 팀 회식 메뉴 뭐가 좋을까요?
3. 그럼 디저트는요?
4. 아까 말한 제 조건 두 가지 다시 말해 줄래요?
5. 비 오는 날이면 메뉴를 바꾸는 게 나을까요?
- **기억할 것:** 매운 것 불가, 견과류 알레르기(2·3·5턴 추천에 반영, 4턴에서 정확히 회상).
- **주로 볼 것:**
  - F2: 견과류 디저트나 매운 메뉴를 추천하면 실패다.
  - F1: "회식"이라는 단어로 업무추진비 규정 검색에 가지 않아야 한다.

### 4. 글 다듬기 (4턴)
1. 이 문장을 공손하게 바꿔 줘: 자료 내일까지 주세요.
2. 조금 더 짧게.
3. 메일 첫 인사 한 줄도 붙여 줘.
4. 처음에 고친 버전으로 다시 보여 줘.
- **기억할 것:**
  - 원문 문장.
  - 1턴의 결과(4턴에서 그 버전을 다시 보여야 한다).
- **주로 볼 것:**
  - F2.
  - F5: 원문만 되풀이하는 경우.
  - F3: 지시문이나 이전 턴을 통째로 붙이는 경우.
  - F4.

### 5. 생략형 후속 (4턴)
1. 주말에 처음 등산 가는데 뭘 챙기면 돼요?
2. 비 오면요?
3. 그건 왜요?
4. 두 번째로 말한 거 좀 더 자세히요.
- **기억할 것:** 주제(초보 등산 준비물). 2턴의 "비"는 같은 등산의 조건이다. 3·4턴은 직전 답의 항목을 가리킨다.
- **주로 볼 것:**
  - F2: 생략된 주어를 잃는 경우.
  - F1: "비 오면요?"가 날씨나 규정 검색으로 가는 경우.

### 6. 일상 → 업무 전환 → 일상 (4턴)
1. 요즘 출장이 많아서 지치네요.
2. 출장 가면 일비는 어떻게 정해져요?
3. 아 그렇구나. 출장 다니면서 체력 관리는 어떻게 해요?
4. 오늘 얘기 고마웠어요.
- **2턴:** 업무 질문이고 기관을 말하지 않았다. 기관을 되묻거나, 검색해도 특정 기관을 임의로 골라 금액을 단정하지 않으면 정상이다. **금액 정답은 정하지 않는다.**
- **3·4턴:** 다시 일상 대화다. 앞 턴의 업무 문서나 출처 블록을 끌고 오지 않아야 한다(F1, F3).
- **주로 볼 것:** F6(2턴), F1(1·3·4턴), F2(3턴의 "출장" 맥락).

### 7. 업무 → 잡담 (4턴)
1. 연가는 1년에 며칠이에요?
2. 인사혁신처 기준으로요.
3. 그렇군요. 휴가 쓰면 어디 가면 좋을까요? 조용한 곳이면 좋겠어요.
4. 바다보다는 산이 좋아요.
- **1·2턴:** 업무 질문이다. 기관 되묻기, 그다음 명시한 기관에서 검색하면 정상이다. 답의 맞고 틀림은 이 시나리오에서 보지 않는다.
- **3·4턴:** 일상 대화다. "휴가"라는 단어로 연가·휴가 규정 검색에 가지 않아야 한다(F1). 조건(조용함, 산)을 반영해야 한다(F2).
- **주로 볼 것:** F1, F2, F3(규정 문구를 덤프하는 경우).

### 8. 새 세션 격리 (5턴, 중간에 새 대화)
1. 제 이름은 박지은이고 다음 주 화요일에 이사해요.
2. 이삿날 챙길 것 세 가지만 알려 주세요.
3. (✎ 새 대화 / `/api/clear`)
4. 제 이름이 뭐라고 했죠?
5. 제가 이사하는 날이 언제였죠?
- **새 대화 전:** 1·2턴에서 이름과 날짜를 기억해도 된다.
- **새 대화 후:** 4·5턴은 **모른다고 해야 정상**이다.
- **실패:**
  - 이름이나 날짜를 맞히면 F7이다.
  - 다른 이름이나 날짜를 지어내는 것도 실패다(F2, 날조).
- **주로 볼 것:** F7, F1(4·5턴이 검색으로 가는지).
