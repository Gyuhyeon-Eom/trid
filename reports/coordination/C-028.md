## 3. 판정

| 항목 | 판정 |
|---|---|
| case 계약 결론 정확 | **원본보다 낮음**(31 → 22, 11:2) |
| case 계약 형식(출처, 확인 불가) | 일부 학습됨(출처 23 vs 18, 확인 불가 3/7). 그러나 256토큰 종료 실패(EOS 3/50)와 반복 퇴화가 큼 |
| 값 계약 회귀 | **불통과**(grammar 98 → 14) |
| 문법 강제 시 값 정답 | 개선(19 → 56). 단 과보류(128/228) 동반 |
| 종합 | **성능 향상 아님.** 기본 버전 교체 근거 없음. 사이트 게시는 "수리 실험판(성능 미확인)"을 유지하되 이 결과(회귀)를 표시할 것을 권고 |

**원인 해석의 한계:**
- 학습 34행, 2 epoch, 데이터 부분집합과 내용 계약 변경이 함께 바뀐 소규모 진단이다. 회귀의 원인을 하나로 확정하지 않는다.
- 다만 관찰은 **출력 길이·종료 학습의 실패**(256토큰 안 EOS 3/50, 반복)를 가리킨다.
- 1.7B 원본도 표 오독과 조건 누락이 많다(원본 결론 31/50). 이것은 이번 학습과 무관한 현재 모델 크기·설정의 한계로 보인다. 수리 실패와는 따로 봐야 한다 [INFERENCE].

**학습 쪽에 전할 오류 유형** (원문 제외):
1. 답 길이 상한 안에서 끝내지 못함(EOS 미학습)
2. "[n] … [Dn]" 형식의 반복 퇴화
3. 답이 있는 문항의 과보류
4. 값 질문에 case 형식으로 길게 답해 지시형 값 계약이 깨짐
5. 표 결재권자·필수 여부 오독(원본과 공통)
