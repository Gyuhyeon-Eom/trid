# B-010: PRISM 공개 UI 경로 확인과 정책연구보고서 100건 파일럿

작성: B, 2026-10-30 KST. 근거 지시: 총괄 판단 B-010 (PRISM 공개 UI 경로 명시 승인).

이번에 하지 않은 것:
- 키가 필요한 포털 API(공공데이터포털 15080254)는 호출하지 않았다.
- 로그인, 401/403, 캡차는 만나지 않았고, 우회도 하지 않았다.
- ALIO 요청, FineWeb 확대, 국회 HTTP 400 두 건 재요청은 하지 않았다.
- A003 입력은 바꾸지 않았다. 최종 시험 문항은 작성하지 않았다.

**결과 요약:**
- 22개 목록 페이지에 있는 과제 214건을 살폈다.
- 권리 조건을 통과한 101건 중 100건의 연구보고서 원문을 확보했다.
- 정제 후보 **92건**(16,594,634자), 격리 **8건**(텍스트 추출 실패).
- 148계열 서명 검사 결과는 일치 0, 부분 검토 0이다. 나머지 852계열은 미확인이다.

## 1. 관리 브라우저에서 확인한 공개 경로

방법: relay 없는 관리 Chromium(`app: {relay: false}`), 허용 도메인 `*.prism.go.kr`, 로그인하지 않음.

| 단계 | 화면 / 응답 근거 |
|---|---|
| 목록 | `https://www.prism.go.kr/homepage/asmt/list`: "총 7,750건"(기본 기간 최근 3년), 10건씩 표시. UI 요청은 `POST api.prism.go.kr/prism-be-asmt/v1/entire/list-organtheme {"asmtNm":"","startDate":"2023.10.30","endDate":"2026.10.30","currentPage":1,"pageSize":10}` |
| 상세 | `/homepage/asmt/6430000-202600098`: 연구보고서 PDF와 "공공누리 [충청북도]가 보유한 [...] (은/는) [제1유형:출처표시] 조건에 따라 이용할 수 있습니다." 표시. UI 요청은 `POST .../v1/entire/info {"mainYn":"N","asmtId":...}` |
| 내려받기 | "다운로드" 클릭 → UI 요청 `POST .../v1/progress/download-file {"asmtId","fileTypeCd":"D0150004","fileSn":1,"fileWkky":"001","pdfTrsfYn":"Y"}`. 인증 헤더 없음, HTTP 200, `application/download`, 3,187,779 바이트 |

이용 조건 확인:
- **이용약관·저작권정책 페이지는 찾지 못했다.**
  - 하단 링크는 "개인정보처리방침"뿐이고, 저작권 표시는 "ⓒ Ministry of the Interior and Safety. All rights reserved."이다.
  - `/homepage/prtl/sitemap/list`는 "찾을 수 없는 페이지"였다.
  - 개인정보처리방침(`/privacyPolicy/privacyPolicy.html`)에는 자동 수집이나 재이용을 제한하는 조항이 없다. 이 문서의 "무단"은 개인정보시스템 무단 접근 통제 문맥이다.
- **문서별 권리는 상세 응답의 공공누리 기록으로 판단했다.**
  - `koglDetail.koglTypeCd`, `cdNm`, `koglAiYn`(공공누리 AI 학습용 표시)
  - `asmtDetail.infoRlsCd`, `koglRlsYn`, `koglCmrcUtztnYn`(상업적 이용), `koglWrgsChgYn`(변경)
- **robots.txt:**
  - `www.prism.go.kr`는 `Disallow:`(빈 값)이다.
  - `api.prism.go.kr`는 404다. 404는 허가도 금지도 아닌 것으로 보고, 아래 보수적 간격을 적용했다.
- **관리 브라우저 세션의 요청:** 홈, 목록, 상세, 파일 1건, 사이트맵(404), 개인정보처리방침 2회. 이 요청들은 UI가 평소대로 보낸 것이라 제한기를 거치지 않았다.

## 2. 수집기와 요청 간격

수집기: `scripts/collect_prism.py`. 커밋 `9041a3e`, `55f32fa`, sha `b7c0b92b…`.

**요청 범위:**
- 위 세 가지 UI 요청만 보낸다.
- 파일은 상세 응답의 `asmtFileList`에 있는 값 그대로 요청한다.
- 401/403, 4xx, JSON이 아닌 응답이 오면 즉시 중단한다(`Stop`).

**TLS:**
- 서버가 중간 인증서를 보내지 않는다.
- 인증서 AIA에 적힌 Sectigo 중간 인증서를 저장소(`scripts/certs/`)에 두고, SHA-256 지문을 고정해 certifi에 더한다. 검증은 켜 둔 상태다.

**권리 기준 (모두 충족해야 원문을 받는다):**
- `infoRlsCd = B0030001`(공개)
- 공공누리 1유형(D0590002) 또는 자유이용(D0590006)
- 상업적 이용 Y, 변경 Y
- 연구보고서 파일(D0150004)이 있음

`koglAiYn`은 받아서 기록한다. 테스트: `tests/test_collect_prism.py`.

**원문 저장:**
- `put_raw_keep`(S3 `If-None-Match`)으로 한 번만 쓴다.
- 위치: `corpus/raw/prism/<asmtId>/info.json`, `<fileTypeCd>-<fileSn>-<fileWkky>.<ext>`

**간격:**
- 이전 요청 종료 + **2 s** 이후에 다음 요청을 시작한다. B-009에서 실증한 제한기다.
- 실제 기록(`logs/requests-prism.go.kr.jsonl`, 파일럿 310건, 11:03:04–11:16:39 KST, pid 2개 순차):

|---|---|
| 이전 종료 → 다음 시작 최소 | **2.0001 s** |
| 시작 → 시작 최소 | 2.0911 s |
| 2 s 미만 시작 간격 | 0 |
| 2초 창 안 최대 시작 수 | 1 |
| 응답 상태 | 모두 200 |
| 요청 내역 | 목록 23, 상세 171, 파일 116 |

파일럿 전 응답 형식 확인용 요청 2건(목록 1, 상세 1)이 따로 있다. 같은 제한기를 거쳤다.

표본 문장:
- **법령 근거 설명:** "청년 1인가구란 「청년기본법」에 근거하여 19세~34세까지의 사람…" (1092000-202500013)
- **조문 인용:** "② 국가와 지방자치단체는 청년의 육체적·정신적 건강 증진을 위한 건강서비스 전달체계를 확립하여야 한다." (1351000-202500033)
- **비교 제도 설명:** "…연방주가 자체적인 법령을 제정할 수 있다" (1270000-202400033)

**한계 (실측):**
- **표가 표 형태로 남지 않는다.** `pdftotext`는 표를 셀 하나당 한 줄로 푼다. 문서당 짧은 줄(20자 미만) 비율의 중앙값이 0.73이다. 표를 학습에 쓰려면 배치를 보존하는 추출이 필요하다. 이번에는 하지 않았다.
- **품질 평가(`PUBLIC_DOCS`)를 통과한 문서는 11/92뿐이다.**
  - 실패 사유: 반복 줄 비율 48 (쪽마다 반복되는 머리말·꼬리말을 지우지 않았다), 줄 끝 문장부호 비율 21, 그 밖 12.
  - 이 실패는 `quality:<사유>` 플래그로만 남겼다. 격리하지 않았다. 사용 여부는 A가 판단한다.
- 따라서 지금 근거로 보일 수 있는 것은 **법령에 근거한 정책 설명과 조문 인용 문장**이다. 표 이해 학습 근거로는 아직 쓸 수 없다.
