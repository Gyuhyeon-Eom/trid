## 2. 런타임·template·system 검증

- **런타임:** 현재 llama.cpp `8ca4060` Metal 빌드에서 text-only로 로드했다. mmproj는 없다. 빌드를 바꾸거나 새로 설치하지 않았다.
- **template:**
  - GGUF에 내장된 Gemma 3 공식 jinja template을 썼다(sha `8d9e3a3c…`). 이 template은 system 내용을 첫 user 턴 앞에 `내용 + "\n\n"`으로 붙인다.
  - 렌더링 결과 `<start_of_turn>user\nSYS\n\nU1<end_of_turn>\n<start_of_turn>model\nA1<end_of_turn>\n<start_of_turn>user\nU2<end_of_turn>\n<start_of_turn>model\n`은 Google 공식 문서(Gemma formatting and system instructions)의 형식과 같다.
  - Google 문서: "user·model 두 역할만 지원하고, system은 첫 user 프롬프트에 넣는다."
  - BOS는 토큰화 단계에서 1개 붙는다.
- **샘플링:** temperature 1.0, top_p 0.95, top_k 64, min_p 0.
  - 출처 1: 맥미니 Ollama 모델의 파라미터(1 / 64 / 0.95)
  - 출처 2: `google/gemma-3-12b-it` 토론 #25의 Gemma 팀 답변(AI Studio 1.0 / 0.95, top_k 64)
  - `google/gemma-3-4b-it`의 `generation_config.json`은 접근 제한(HTTP 401)이라 **직접 확인하지 못했다.**
  - min_p 0은 llama.cpp 기본값 0.05 대신 명시한 값이다.
- **공통 조건:** BASELINE-COMPARE-002와 같다.
  - 시스템 프롬프트: 서비스 `CHAT_SYSTEM`
