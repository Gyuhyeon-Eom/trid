# BUDGET-PLAN-C: C 작업별 비용 예약안 (BUDGET-300K-001)

작성: 2026-10-30 KST. 현재 상태는 **hold**다. C의 GPU 작업은 모두 정지·종료 상태이며(`BUDGET-HOLD-C.md`), 이 문서는 예약안일 뿐 기동하지 않았다. 내부 예약 한도는 C 5만 원(dev2 검증과 관문)이다.

## 1. 단가와 가정

- **공식 단가:** AWS Pricing API, `AmazonSageMaker`, ap-northeast-2, `APN2-Train:ml.g6e.12xlarge`, **$16.1252/시간**(effectiveDate 2026-10-01).
  - 학습 작업 저장소(400 GB ML 스토리지)는 작업 시간 동안 시간당 $0.1 미만으로 보고 상한에 $0.1을 더한다 [INFERENCE: 단가 미조회].
- **환율·세금:** 1 USD = 1,450원(보수적 가정), 부가세 10%.
- **과금 시간:** SageMaker는 작업 시작부터 종료까지 초 단위로 과금하며, 컨테이너 기동과 모델 다운로드 시간도 포함된다.
- **이전 실측:**
  - 기동(컨테이너, 두 모델 다운로드와 sha 확인, 서버 정상)까지 약 12분.
  - 검증 45건(gpt-oss, 8 slot)에 약 5분.
  - 생성 초안 52건(Qwen 사고 모드, 8 slot)에 약 9분.
- **실행 조건:**
  - Spot은 쓰지 않는다. 절감이 실측되지 않았으므로 온디맨드 단가로 상한을 잡는다.
  - 온디맨드 자동 대체, 자동 재시도, 자동 후속 작업은 없다.

## 3. 예약 요청 2 — 관문 (dev2 결과를 보고 따로 승인)

| 항목 | 값 |
|---|---|
| 작업 | `C-010/gate-protocol.md`에 고정한 관문. 유형별 순번 10–49 기록(240건)을 생성 → 점검 → 검증하고, 유형별 채택 앞 20건을 AI 검토 |
| 인스턴스 | `ml.g6e.12xlarge` × 1. 두 모델 적재. 초안과 검증을 GPU 쌍별로 동시에 처리 |

| 추정 사용 | 약 62분(기동 12분 + 초안 240건 약 41분, 검증은 초안과 겹쳐 진행 + 꼬리 검증 약 9분) |
| 추정 비용 | 약 $16.7 → **약 26,600원** |
| **예약 상한** | 80분 × $16.1252 + $0.1 = $21.60 → **약 34,500원** |
| 한계 | 채택률이 낮은 유형(개발 측정에서 수치변화 3/5, 설명 2/7, 다중근거 0/8)은 240건 안에서 채택 20건이 안 될 수 있다. 그런 유형은 부족분을 그대로 보고하고 추가 실행을 따로 요청한다. 시간 상한에 걸리면 저장된 부분까지만 보고한다 |

- **C 누적 예약(두 요청 상한 합계):** 15,200 + 34,500 = **49,700원**으로, 5만 원 이내다.
- **해석:** 600건(유형별 100) 확대는 이 예약에 들어 있지 않으며 사전 승인 대상도 아니다. 관문을 통과한 유형이 있을 때 따로 견적한다.

- 삭제는 별도 승인 사항이라 실행하지 않았다. 소유 미확정 자원은 건드리지 않는다.
