## 4. 파일럿에서 발견해 수정한 결함 (확대 전)

2. 자유 생성 답이 원문 구간이 아님(60건 중 42건 점검 탈락) → 번호 선택 방식으로 바꿔 53/60 통과.

4. 수치변화가 연도·날짜를 편집해 '2256년' 같은 비정상 값 발생 → 수량 단위만 편집하도록 했다.
5. 판정 모델이 관대해 결함 항목을 채택 → 결정적 형식 규칙과 내용 일치 관문을 추가했다.
6. 조건·예외 표지를 답 자체에서 찾아 정상 항목까지 탈락 → 답 주변 ±40자에서 찾도록 했다.
7. 설명 결론 후보가 목적 구절이 아님 → 절 시작부터 목적 표지까지의 구간만 후보로 제시했다.

## 6. 남은 부족과 근거

- 유형별 100건의 '조립'은 됐지만, 의미 정답률로 환산하면 유효 후보는 대략 다중근거 15, 조건 35, 예외 45, 설명 50, 수치 60, 표 55건 수준으로 추정된다(표본 비율을 적용한 추정이며 실측 수량이 아님). 목표 대비 부족하다.
- 수정 제안(새 학습 없음, 데이터 경로만):
  - (a) **수치변화**: 편집 대상 숫자가 문서 전체(제목 포함)에서 한 번만 나오고, 합계·비율·'총/계/중' 문맥이 아닐 때만 편집한다. 결정적 규칙이다.
  - (b) **표**: 열 이름이 머리글에서 유일하지 않거나 상위 머리글이 있는 표는 제외한다. 결정적 규칙이다.
  - (c) **조건·예외·설명**: 질문이 답 구간의 핵심어를 포함하면 탈락, 지시어('이 사업/이 과정')로 시작하면 탈락. 결정적 규칙이다.
  - (d) **다중근거**: 2.1B 생성기로는 성립이 어렵다. 같은 사업의 '대상-금액', '기간-장소'처럼 원문 구조(▲·○ 목록, 일시/장소 줄)에서 두 값을 규칙으로 뽑고, 생성기는 질문만 쓰게 바꿔야 한다.
  - (a)~(c)는 기존 산출물에 GPU 없이 즉시 재적용할 수 있다. 재적용 후 같은 방식의 120건 재검토로 개선 여부를 측정한다. (d)는 새 초안이 필요하므로 GPU 재기동이 필요하다(재기동 후 수 분이면 서빙 가능).
