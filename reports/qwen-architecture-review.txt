Qwen3 공개 구현 검토 및 trid 적용 기록 — 2026-10-27

범위
사용자 요청에 따라 공개된 구조와 구현을 비교했다. Qwen 가중치, 토크나이저,
학습 데이터는 내려받거나 사용하지 않았다. Qwen3 구조 전체를 복제하지 않고
기존 trid 구현에 GQA 및 Q/K 정규화의 선택 기능을 직접 작성했다.
현재 장기 학습의 설정/데이터/프로세스, active-model.json, 웹 배포는 변경하지 않았다.

공개 코드와 공개 가중치가 있다고 전체 원본 학습 자료/재현 가능한 전체 학습
파이프라인까지 모두 제공된다는 뜻은 아니다. 향후 소스를 직접 복사/수정하여
배포하는 경우 해당 파일의 저작권/라이선스/NOTICE 및 변경 표시 조건을 확인하고
유지해야 한다. 이번 변경은 외부 코드 파일을 벤더링하지 않았다.

비교 결과
- 이미 trid에 있음: decoder-only Transformer, pre-RMSNorm, SwiGLU,
  RoPE, bias 없는 QKV, 입력/출력 임베딩 공유, causal SDPA, KV cache.
- 추가: kv_heads (기본 None, 기존 heads와 같음). K/V를 여러 query head가 공유.
  Q/K/V를 합친 기존 projection과 interleaved RoPE는 유지한다.
- 추가: qk_norm (기본 false). head 차원별 RMSNorm을 RoPE 전에 적용한다.
  기존 trid RMSNorm의 epsilon 1e-5를 사용하므로 Qwen3 전체 수치 구현과 같지 않다.
- 두 옵션은 독립적으로 사용할 수 있다. 기본 설정에서는 새 학습 파라미터가 없고
  기존 state_dict와 optimizer 파라미터 순서를 유지한다.
- 캐시에 작은 K/V를 저장하고 SDPA 호출 전에만 query head 수로 반복 확장한다.
  이는 CPU/MPS 호환 구현이며, attention 임시 메모리/전체 메모리 또는 속도가
  같은 비율로 줄어든다는 뜻은 아니다.

설정과 수치
기존: configs/korean-medium-91m.json
실험: configs/korean-medium-gqa-qknorm-experimental.json
공통: vocab 8192, dim 768, 12 layers, 12 query heads, hidden 2048, context 1024.
실험: 4 KV heads, Q/K norm 사용.
                            파라미터        KV 캐시 (batch 1, FP32, 1024 tokens)
기존                        91,245,312      72 MiB
Q/K norm만                  91,246,848      72 MiB
GQA만                       81,808,128      24 MiB
GQA + Q/K norm              81,809,664      24 MiB
캐시 수치는 레이어 전체의 K/V 텐서 저장량이며 allocator overhead와 임시 텐서는 제외.

검증
reports/qwen-architecture-compatibility.json에 소스/가중치 SHA256과 비교 결과 저장.
- 수정 전 소스를 불러와 기존 기본 설정의 초기화, state_dict 키/순서, gradient를
  비교했으며 CPU에서 오차 0.
- 실제 91M 학습 가중치 한 스냅샷을 수정 전후 구현에 strict load하고 길이 1/32/128의
  forward 및 cached forward를 비교했으며 CPU에서 logit 최대 오차 0.
- tests/test_attention_options.py: CPU/MPS에서 causal masking, 한 토큰/여러 토큰
  cached decoding, 유한한 gradient, 그룹별 K/V 공유 reference, 설정 검증,
  checkpoint roundtrip, 기존 설정 호환성 확인.
- 전체 관련 테스트 실행 결과: reports/qwen-architecture-tests.txt.

도입 판단
현재 진행 중인 91M 사전학습은 비교 기준으로 끝까지 유지한다. 구조 옵션은
체크포인트 설정을 임의로 바꿔 켜는 기능이 아니다. GQA는 가중치 형태가 바뀌고,
Q/K norm은 새 파라미터와 연산을 추가하므로 별도 학습/검증이 필요하다.
이번 작업에서는 새 구조의 장기 학습을 시작하거나 자동 예약하지 않았다.
Q/K norm의 안정성 및 GQA의 메모리 절약은 시험할 근거이지 정확도 향상 보장은 아니다.

후속 비교 기준
동일 tokenizer, 데이터 split, 처리 토큰 수, schedule, batch, seed 조건에서
기존 / QK만 / GQA만 / 둘 다를 별도 출력 경로로 비교한다. 파라미터 수 감소도
함께 보고하며, 가능하면 복수 seed를 사용한다. 먼저 작은 예산으로 발산/속도/
메모리와 검증 손실을 확인한 후 의미 있는 학습 예산으로 대화 및 RAG 정확도를
평가한다. 검증 손실만으로 기본 모델을 바꾸지 않는다.
한국어 자연스러움, 질문 의도, 숫자/기관명 정확도, 근거 인용, 답 없는 질문,
오래된/충돌하는 자료 처리, 학습에 없는 실제 문서 질문을 따로 측정한다.
기존 합성 테스트는 이미 개발에 사용했으므로 독립 평가라고 주장하지 않는다.

현재 더 큰 한계
trid 사전학습은 현재 위키 기반 자료와 1억 토큰 예산이다. 코드 변경만으로
대규모 공개 모델의 언어 능력이나 RAG 정확도를 재현할 수 없다. 다양하고 품질이
검증된 한국어 자료, 문서에 근거한 답변 학습, 적절한 검색/재정렬, 독립 평가가
필요하다. 토크나이저 교체와 장문 문맥 확장 역시 현재 학습 중에는 적용하지 않고
별도 실험으로 검증해야 한다.
